Lecture 6: CSS Box Model & Layout

(Spacing and Positioning)

Summary

This lecture explains the CSS Box Model, which is essential for layout and spacing. It covers margins, borders, padding, and the actual content area.

Topics Covered

  • Content, Padding, Border, Margin
  • Box Sizing
  • Display Property (Block, Inline, Inline-Block)

Example Code

div {
    width: 200px;
    padding: 20px;
    border: 2px solid black;
    margin: 10px;
}
