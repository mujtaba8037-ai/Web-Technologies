Lecture 5: CSS Selectors

(Targeting HTML Elements)

Summary

This lecture dives deep into CSS Selectors, which are patterns used to select the elements you want to style. It covers element, class, and ID selectors.

Topics Covered

  • Element Selector
  • Class Selector (.)
  • ID Selector (#)
  • Grouping Selectors

Example Code

<style>
    .my-class { color: red; }
    #my-id { color: green; }
</style>
<p class="my-class">Class Example</p>
<p id="my-id">ID Example</p>
