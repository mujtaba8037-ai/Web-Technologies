Lecture 3: HTML Forms and Media

(User Input and Multimedia)

Summary

This lecture focuses on creating interactive web pages using HTML forms to collect user input. It also covers embedding media like images, audio, and video into web pages.

Topics Covered

  • Form Elements (Input, Label, Button)
  • Input Types (Text, Password, Email, Submit)
  • Embedding Audio and Video

Example Code

<form>
    <label>Name:</label>
    <input type="text" name="name">
    <input type="submit" value="Submit">
</form>
