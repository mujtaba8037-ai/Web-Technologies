Lecture 4: Introduction to CSS

(Styling the Web)

Summary

This lecture introduces Cascading Style Sheets (CSS), the language used to style and layout web pages. It covers the different ways to apply CSS: Inline, Internal, and External.

Topics Covered

  • CSS Syntax (Selectors, Properties, Values)
  • Inline CSS
  • Internal CSS
  • External CSS

Example Code

<style>
    p {
        color: blue;
        font-size: 18px;
    }
</style>
